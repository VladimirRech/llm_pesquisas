## Problema com Python, PIP e Linux Debian
* O Linux Debian versão 13 trabalha em modo protegido e por padrão não permite usar o PIP.
* A solução recomendada é usar o modo de ambiente virtual que está documentado no arquivo
  `prompt_e_solu_o_pep_668_no_debian.md`.

## Requisitos

### Instalando o qwen 2.5 0.8
Digitar os comandos abaixo no terminal:
```bash
$ ollama pull qwen3.5:0.8b
# Instalando o embeding
$ ollama pull qwen3-embedding:8b
```

Instalar também o qwen3-embeding.
Este é o responsável por rodar o aprendizado do LLM e criar a estrutura para o 
agente consultar os dados localmente.

Exemplo de execução de modelos:
```bash
$ ollama run qwen3.5:08b
```

Neste exemplo vai buscar on line.

### Listando os modelos instalados
```bash
$ ollama list
```
